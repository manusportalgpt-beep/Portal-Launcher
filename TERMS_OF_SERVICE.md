## 2. Описание сервиса

Portal Launcher — это сторонний лаунчер для Minecraft, предназначенный для упрощения управления версиями игры, модами, ресурс-паками и сборками. Лаунчер не предоставляет доступ к платному контенту Minecraft незаконным путем и требует наличия действующей лицензии Microsoft/Mojang для входа в многопользовательские режимы официальных серверов.

## 3. Правила поведения

При использовании Лаунчера и связанных с ним сервисов (включая интеграцию с Discord) пользователю запрещается:
1.  Использовать Лаунчер для запуска вредоносного ПО, вирусов или кода, нарушающего работу других систем.
2.  Осуществлять обратную разработку (reverse engineering) Лаунчера с целью нарушения его безопасности или создания читерского ПО.
3.  Использовать Лаунчер для нарушения условий использования Minecraft (EULA Mojang/Microsoft).
4.  Распространять модифицированные версии Лаунчера без указания авторства оригинального проекта.

## 4. Интеграция со сторонними сервисами

Лаунчер может включать функции интеграции со сторонними платформами, такими как **Discord Rich Presence**. Используя эти функции, вы соглашаетесь с тем, что определенная информация о вашей активности (название сборки, время игры, статус сервера) может передаваться в эти сервисы для отображения в вашем профиле. Вы можете отключить эти функции в настройках Лаунчера в любое время.
