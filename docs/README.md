Статический сайт для GitHub Pages (папка /docs). Описание и инструкции взяты из README репозитория.

Развертывание:
1) Включите GitHub Pages в настройках репозитория, выберите ветку main и папку /docs.
2) Сайт будет доступен по: https://manusportalgpt-beep.github.io/Portal-Launcher/
