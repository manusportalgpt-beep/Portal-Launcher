Portal Launcher

Лаунчер Minecraft — управление сборками, модами, шейдерами и безопасный агент, который проверяет сборки перед запуском.

Платформа: Windows (инсталлятор .exe). Для Linux/macOS смотрите «Сборка из исходников».

Почему Portal?

  • Агент проверяет сборку — нет «догадок»
  • Импорт/экспорт модпаков: Modrinth, Prism
  • Изоляция инстансов, Java Manager, автообновления

Ключевые возможности

Поддержка сборок

Fabric, Forge, Quilt, NeoForge; импорт из Modrinth и Prism; экспорт в .mrpack и ZIP.

OpenPortal — агент

Агент анализирует содержимое сборки, не делает догадок и помогает исправлять конфиги и краши.

Обновления через Releases

Автоматическая проверка релизов, загрузка инсталлятора из GitHub Releases.

Инстансы и Java

Изоляция, RAM и Java per-instance, встроенный Java Manager.

Как скачать и установить

  1. Откройте страницу релизов: Releases › Последний релиз.
  2. Найдите файл с расширением .exe — это инсталлятор для Windows. Если .exe нет — используйте ZIP.
  3. Скачайте и запустите инсталлятор. Следуйте инструкциям установщика.
  4. После установки откройте программу — она предложит загрузить Java и необходимые лоадеры.

Скачать напрямую

Нажмите кнопку «Скачать последний релиз» — сайт попытается автоматически найти файл .exe (или ZIP) в latest release и предложит прямую ссылку.

Сборка из исходников

pnpm install
pnpm tauri dev      # запуск в режиме разработки
pnpm tauri build    # сборка релизной версии

# фронтенд отдельно
pnpm build

Требования: Node.js 20+, pnpm, Rust и Tauri prerequisites. Подробно — в README репозитория.

Галерея

FAQ

Можно ли запустить лаунчер на Linux или macOS?

Да — соберите из исходников (см. раздел Сборка). На Linux нужен webkit2gtk, на macOS — Xcode CLT.

Как добавлять моды?

Через интерфейс сборки или импорт из Modrinth/CurseForge/Prism.
