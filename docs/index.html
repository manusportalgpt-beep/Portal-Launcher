Portal Launcher

Лаунчер Minecraft — управление сборками, модами, шейдерами и безопасный агент, который проверяет сборки перед запуском.

Скачать последний релиз Все релизы

Платформа: Windows (инсталлятор .exe). Если вы используете Linux или macOS — смотрите раздел «Сборка из исходников».

Ключевые возможности

  • Поддержка сборок

    Fabric, Forge, Quilt, NeoForge; импорт из Modrinth и Prism; экспорт в .mrpack и ZIP.

  • AI — OpenPortal

    Агент анализирует содержимое сборки, не делает догадок и помогает исправлять конфигурации и краши.

  • Обновления через Releases

    Проверка обновлений и автоматическая загрузка установщика из GitHub Releases.

  • Изоляция инстансов

    Каждая сборка — свой профиль с RAM, Java и аргументами.

Как скачать и установить

  1. Откройте страницу релизов: Releases › Последний релиз.
  2. Найдите файл с расширением .exe — это инсталлятор для Windows. Если .exe нет, в релизе должен быть ZIP с портативной сборкой.
  3. Скачайте файл и запустите инсталлятор. Инсталлятор поставит Portal Launcher в систему и добавит ярлык на рабочий стол.
  4. После установки откройте программу, она сама предложит проверить обновления и предложит загрузить дополнительные компоненты (Java, лоадеры и т. п.).

Если вы хотите скачать напрямую

Мы рекомендуем пользоваться страницей релизов. Если нужен прямой доступ к артефакту, откройте релиз и скачайте нужный файл. Политика релизов и формат — описаны в README » Как работают обновления.

Сборка из исходников

Подходит для Linux / macOS и продвинутых пользователей. Быстрая инструкция из README:

pnpm install
pnpm tauri dev      # запуск в режиме разработки
pnpm tauri build    # сборка релизной версии

# фронтенд отдельно
pnpm build

Требования: Node.js 20+, pnpm, Rust, Tauri prerequisites (Visual Studio Build Tools на Windows, webkit2gtk на Linux, Xcode CLT на macOS). Подробно: README » Сборка из исходников.
